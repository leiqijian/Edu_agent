    EduAgent 数据库表结构详解¶

    文件说明：本文档对 init_db.sql 中所有建表字段进行中文注释说明，适合开发者快速理解数据模型。

    目录¶

    1. users — 用户表
    2. knowledge_pending_queue — 知识库待补充队列表
    3. exams — 试卷表
    4. questions — 试题表
    5. scoring_points — 评分要点表
    6. exam_submissions — 学生答卷提交表
    7. exam_reviews — 答卷批改详情表
    8. resume_reviews — 简历审查表
    9. interview_questions — 面试题库表
    10. interview_sessions — 模拟面试会话表
    11. qa_sessions — 问答会话表
    12. 触发器说明

    1. users — 用户表¶

    存储系统中所有用户信息，包括学生、教师和管理员。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 用户唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID，用于多校区数据隔离，默认 tenant_default
    username VARCHAR(64) NOT NULL 用户名（登录名）
    email VARCHAR(128) NOT NULL 邮箱地址，同租户内唯一
    password_hash VARCHAR(256) NOT NULL bcrypt 加密后的密码，绝不存明文
    role VARCHAR(16) NOT NULL 角色：student 学生 / teacher 教师 / admin 管理员
    class_id UUID 可为空 所属班级ID（预留字段，暂未关联班级表）
    is_active BOOLEAN NOT NULL 账号是否启用，默认 true
    created_at TIMESTAMPTZ NOT NULL 账号创建时间
    updated_at TIMESTAMPTZ NOT NULL 账号最后修改时间（触发器自动维护）

    约束说明： - UNIQUE (tenant_id, email)：同一租户内邮箱不可重复，不同租户可以有相同邮箱

    索引： - idx_users_tenant_id：按租户查询加速 - idx_users_role：按角色筛选加速 - idx_users_class_id：按班级查询加速

    2. knowledge_pending_queue — 知识库待补充队列表¶

    记录学生提问但知识库无法自信回答的问题，供教师补充知识库使用。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 记录唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    question TEXT NOT NULL 学生提出的原始问题内容
    student_id UUID 可为空 提问学生的ID，关联 users(id)
    confidence FLOAT NOT NULL RAG 检索置信度（0~1），越低说明知识库越缺这块内容
    status VARCHAR(16) NOT NULL 处理状态：pending 待处理 / resolved 已解决 / dismissed 已忽略
    resolved_by UUID 可为空 处理人的用户ID，关联 users(id)
    resolved_at TIMESTAMPTZ 可为空 问题被处理的时间
    created_at TIMESTAMPTZ NOT NULL 问题入队时间

    索引： - idx_knowledge_pending_queue_tenant_id：按租户查询加速 - idx_knowledge_pending_queue_status：按状态筛选加速

    3. exams — 试卷表¶

    存储教师创建的试卷基本信息。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 试卷唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    title VARCHAR(256) NOT NULL 试卷标题
    description TEXT 可为空 试卷描述 / 考试说明
    due_date TIMESTAMPTZ 可为空 截止提交时间
    created_by UUID 可为空 出卷教师的用户ID，关联 users(id)
    is_active BOOLEAN NOT NULL 试卷是否有效 / 启用，默认 true
    created_at TIMESTAMPTZ NOT NULL 试卷创建时间
    updated_at TIMESTAMPTZ NOT NULL 试卷最后修改时间（触发器自动维护）

    索引： - idx_exams_tenant_id：按租户查询加速

    4. questions — 试题表¶

    存储每张试卷下的具体题目信息。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 题目唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    exam_id UUID 可为空 所属试卷ID，关联 exams(id)，试卷删除则题目**级联删除**
    question_no INT NOT NULL 题目序号（第几题）
    question_type VARCHAR(16) NOT NULL 题型：single_choice 单选 / multi_choice 多选 / judge 判断 / short_answer 简答 / code 编程
    content TEXT NOT NULL 题目内容
    correct_answer TEXT 可为空 参考答案
    score INT NOT NULL 该题满分分值，默认 10 分
    knowledge_tag VARCHAR(128) 可为空 知识点标签，用于学生薄弱点分析
    created_at TIMESTAMPTZ NOT NULL 题目创建时间

    索引： - idx_questions_exam_id：按试卷查题目加速 - idx_questions_knowledge_tag：按知识点统计加速

    5. scoring_points — 评分要点表¶

    存储主观题（简答/编程）的细化评分要点，供 AI 和教师打分参考。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 要点唯一标识，自动生成
    question_id UUID 可为空 所属题目ID，关联 questions(id)，题目删除则**级联删除**
    point_desc TEXT NOT NULL 评分要点描述（如：提到线程安全得 2 分）
    point_score INT NOT NULL 该要点对应的分值
    is_active BOOLEAN NOT NULL 该要点是否启用，默认 true
    confirmed_by UUID 可为空 确认该要点的教师ID，关联 users(id)
    confirmed_at TIMESTAMPTZ 可为空 教师确认该要点的时间
    created_at TIMESTAMPTZ NOT NULL 要点创建时间

    索引： - idx_scoring_points_question_id：按题目查要点加速

    6. exam_submissions — 学生答卷提交表¶

    记录每个学生对每张试卷的提交情况，一人一卷只能提交一次。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 提交记录唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    exam_id UUID 可为空 对应试卷ID，关联 exams(id)
    student_id UUID 可为空 提交学生ID，关联 users(id)
    source VARCHAR(16) NOT NULL 提交来源：word Word上传 / online 在线作答 / miniapp 小程序，默认 word
    word_minio_path VARCHAR(512) 可为空 Word 答卷文件在 MinIO 中的存储路径
    status VARCHAR(16) NOT NULL 批改状态：submitted 已提交 → ai_processing AI处理中 → pending_review 待人工复核 → reviewed 已复核 → published 已发布
    submitted_at TIMESTAMPTZ NOT NULL 学生提交时间
    published_at TIMESTAMPTZ 可为空 成绩发布给学生的时间
    weak_points JSONB 可为空 AI 分析出的薄弱知识点（JSON格式）
    weak_points_summary TEXT 可为空 薄弱点的文字总结
    created_at TIMESTAMPTZ NOT NULL 记录创建时间
    updated_at TIMESTAMPTZ NOT NULL 记录最后修改时间（触发器自动维护）

    约束说明： - UNIQUE (exam_id, student_id)：同一学生对同一试卷只能提交一次

    索引： - idx_exam_submissions_tenant_id：按租户查询加速 - idx_exam_submissions_exam_id：按试卷查所有提交加速 - idx_exam_submissions_student_id：按学生查所有提交加速 - idx_exam_submissions_status：按批改状态筛选加速

    7. exam_reviews — 答卷批改详情表¶

    存储每道题的 AI 批改结果和教师复核结果，是批改系统的核心表。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 批改记录唯一标识，自动生成
    submission_id UUID 可为空 所属答卷ID，关联 exam_submissions(id)，答卷删除则**级联删除**
    question_id UUID 可为空 对应题目ID，关联 questions(id)
    question_type VARCHAR(16) NOT NULL 题型（冗余存储，方便查询，无需再 JOIN questions 表）
    knowledge_tag VARCHAR(128) 可为空 知识点标签（冗余存储，方便统计薄弱点）
    student_answer TEXT 可为空 学生的作答内容
    ai_score INT 可为空 AI 给出的分数
    ai_feedback TEXT 可为空 AI 给出的评语 / 反馈
    ai_raw_result JSONB 可为空 AI 返回的完整原始 JSON 结果（保留原始数据方便调试）
    teacher_score INT 可为空 教师复核后给出的分数
    teacher_comment TEXT 可为空 教师的批注评语
    final_score INT 可为空 最终得分（优先取教师分，否则取AI分）
    needs_review BOOLEAN NOT NULL 是否需要人工复核，默认 false
    reviewed_by UUID 可为空 复核教师的用户ID，关联 users(id)
    reviewed_at TIMESTAMPTZ 可为空 教师完成复核的时间
    created_at TIMESTAMPTZ NOT NULL 批改记录创建时间
    updated_at TIMESTAMPTZ NOT NULL 批改记录最后修改时间（触发器自动维护）

    索引： - idx_exam_reviews_submission_id：按答卷查所有题目批改结果加速 - idx_exam_reviews_needs_review：筛选待人工复核的记录加速 - idx_exam_reviews_knowledge_tag：按知识点统计加速

    8. resume_reviews — 简历审查表¶

    记录学生上传简历后的 AI 审查结果。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 审查记录唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    student_id UUID 可为空 学生用户ID，关联 users(id)
    pdf_minio_path VARCHAR(512) NOT NULL 简历 PDF 在 MinIO 中的存储路径
    structured_data JSONB 可为空 AI 解析出的简历结构化数据（教育经历 / 工作经历 / 技能等）
    scores JSONB 可为空 各维度评分（如格式分 / 内容分 / 完整度等）
    issues JSONB 可为空 发现的问题列表（如：缺少项目经验 / 格式混乱等）
    summary JSONB 可为空 综合评价总结
    status VARCHAR(16) NOT NULL 处理状态：pending 待处理 / processing 处理中 / done 已完成 / failed 失败
    error_msg TEXT 可为空 处理失败时的错误信息
    created_at TIMESTAMPTZ NOT NULL 简历提交时间
    updated_at TIMESTAMPTZ NOT NULL 最后更新时间（触发器自动维护）

    索引： - idx_resume_reviews_tenant_id：按租户查询加速 - idx_resume_reviews_student_id：按学生查所有简历加速 - idx_resume_reviews_status：按处理状态筛选加速

    9. interview_questions — 面试题库表¶

    存储系统内置的模拟面试题目。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 题目唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    content TEXT NOT NULL 面试题目内容
    difficulty VARCHAR(8) NOT NULL 难度：easy 简单 / medium 中等 / hard 困难，默认 medium
    tags JSONB NOT NULL 技术标签列表，如 ["Java","Spring","多线程"]
    target_position VARCHAR(128) NOT NULL 目标岗位，如 "Java后端"，默认 general 通用
    is_active BOOLEAN NOT NULL 题目是否启用，默认 true
    created_by UUID 可为空 出题人用户ID，关联 users(id)
    created_at TIMESTAMPTZ NOT NULL 题目创建时间
    updated_at TIMESTAMPTZ NOT NULL 题目最后修改时间（触发器自动维护）

    索引： - idx_interview_questions_tenant_id：按租户查询加速 - idx_interview_questions_target_position：按目标岗位筛选加速 - idx_interview_questions_difficulty：按难度筛选加速 - idx_interview_questions_is_active：筛选启用题目加速

    10. interview_sessions — 模拟面试会话表¶

    记录每次模拟面试的完整过程和评估结果。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 会话唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    student_id UUID 可为空 参加面试的学生ID，关联 users(id)
    session_id VARCHAR(128) NOT NULL 业务层会话ID（应用层生成）
    thread_id VARCHAR(128) NOT NULL UNIQUE LLM 对话线程ID，全局唯一（用于恢复对话上下文）
    target_position VARCHAR(128) NOT NULL 本次模拟面试的目标岗位，默认空字符串
    resume_review_id UUID 可为空 关联的简历审查ID，用于基于简历个性化出题
    summary TEXT 可为空 面试过程文字总结
    report JSONB 可为空 详细面试报告（各维度评分 / 表现分析等）
    overall_score INT 可为空 面试综合评分
    status VARCHAR(16) NOT NULL 面试状态：in_progress 进行中 / finished 已结束
    finished_at TIMESTAMPTZ 可为空 面试结束时间
    created_at TIMESTAMPTZ NOT NULL 面试开始时间
    updated_at TIMESTAMPTZ NOT NULL 最后更新时间（触发器自动维护）

    索引： - idx_interview_sessions_tenant_id：按租户查询加速 - idx_interview_sessions_student_id：按学生查历史面试加速 - idx_interview_sessions_session_id：按业务会话ID查询加速 - idx_interview_sessions_status：按状态筛选加速

    11. qa_sessions — 问答会话表¶

    记录学生与 AI 问答助手的对话会话。

    字段 类型 约束 说明
    id UUID PRIMARY KEY 会话唯一标识，自动生成
    tenant_id VARCHAR(64) NOT NULL 租户ID
    student_id UUID 可为空 提问学生ID，关联 users(id)
    course_id VARCHAR(128) 可为空 所属课程ID（预留字段，暂未关联课程表）
    thread_id VARCHAR(128) NOT NULL UNIQUE LLM 对话线程ID，全局唯一（用于恢复对话上下文）
    summary TEXT 可为空 对话历史摘要（用于长对话压缩，避免超出上下文窗口）
    summary_version INT NOT NULL 摘要版本号，每次压缩对话时自增，默认 0
    created_at TIMESTAMPTZ NOT NULL 会话创建时间
    updated_at TIMESTAMPTZ NOT NULL 会话最后活跃时间（触发器自动维护）

    索引： - idx_qa_sessions_tenant_id：按租户查询加速 - idx_qa_sessions_student_id：按学生查历史问答加速 - idx_qa_sessions_thread_id：按线程ID精确查询加速

    12. 触发器说明¶

    系统为所有含 updated_at 字段的表创建了自动更新触发器，无需业务代码手动维护修改时间。

    -- 触发函数
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

    覆盖的表（共8张）：

    表名 触发器名
    users trg_users_updated_at
    exams trg_exams_updated_at
    exam_submissions trg_exam_submissions_updated_at
    exam_reviews trg_exam_reviews_updated_at
    resume_reviews trg_resume_reviews_updated_at
    interview_sessions trg_interview_sessions_updated_at
    interview_questions trg_interview_questions_updated_at
    qa_sessions trg_qa_sessions_updated_at

    触发时机：每次执行 UPDATE 操作前（BEFORE UPDATE），自动将该行的 updated_at 设置为当前时间。
